# 문제정의서 (5칸)

| 칸 | 내용 |
|---|---|
| ① 현재 업무 | A부 국회 업무 총괄 담당자가 요구서를 접수하면 문항 단위로 대장에 기록하고, 조직도·배분기준표를 확인해 주관 과와 협조 과를 정해 배분한다. 각 과가 답변과 근거를 회신하면 총괄 담당자가 취합·누락 및 형식 점검을 거쳐 결재 후 제출하고, 재배분·수정 제출을 포함한 처리 이력을 남긴다. 2026년 접수대장은 문항별 520행이며 배분 과는 26개, 그중 공통 배분은 70건이다. 근거: 지침재료의 인수인계서·대응계획·업무메일·구두지시 메모, `data/요구자료_접수대장_2026국감_520건.csv`. |
| ② 문제 | **시간:** PDF·한글 요구서의 문항 분해, 기준표 대조, 미회신·누락 확인을 사람이 반복한다. 단계별 소요시간은 대장에 없어 실측 기준선이 없다. **오류:** 문항·요구기간·비고 누락, 중복 접수, 잘못된 기한·부서명·합계 등이 지침의 점검 사례로 제시된다. 대장은 오류 발생 횟수를 기록하지 않는다. **사람마다 다른 점:** 여러 과의 키워드가 겹치거나 기준표에 없을 때 소관 판단이 달라질 수 있다. **이력 단절:** 재배분의 사유·판단자·시각을 덮어쓰면 후임자와 감사 대응 시 판단 근거를 추적하기 어렵다. 현재 대장에는 최종 배분과 처리상태만 있으며 변경 이력 열은 없다. 제출완료 외 상태는 108건(기한연장 55건, 보완요청 53건)으로, 후속 확인 대상을 구분할 필요가 있다. |
| ③ 목표 | 2026년 접수대장 520건에 적용할 수 있도록 문항 단위 기록, 소관 과 **후보** 추천, 누락·이상 항목 표시, 판단 이력 기록을 지원한다. 별도 시험 요구문항 **40건**에서 1순위 소관 과 추천 정확도 **75% 이상(30건 이상)**을 달성한다. 이 수치는 사용자 지정 통과 목표이며 현재 정확도 실측치는 없다. 확인필요·재배분·수정 사유와 담당자·시각이 조회되도록 한다. 처리시간 단축이나 오류 감소율은 기준선이 없으므로 수치 목표로 단정하지 않는다. |
| ④ 범위 | **만들 것:** 요구서 문항 분해 및 대장 입력 보조, 배분기준표·조직도에 근거한 주관 과 후보와 협조 과 후보 제시, 우선순위 동률·무일치·공통 문항의 확인필요 표시, 중복·기한·기간·문항·부서명 등 누락·이상 점검, 사람이 확정한 배분과 변경 사유·담당자·시각의 이력 관리. **만들지 않을 것:** 답변 작성·수정, 결재, 국회 제출 또는 제출 여부의 자동 결정. **사람 판단:** 중복 여부와 잘못된 날짜의 확인, 동률·무일치·복수 소관의 주관/협조 확정, 예외 처리 및 점검 표시의 수정·반영 여부는 담당자가 결정한다. 실제 요구자료는 내부 시스템에서만 다루고 개인정보가 있는 자료를 외부 AI에 넣지 않는다. |
| ⑤ 검증 기준 | 별도 시험 요구문항 **40건**의 정답 주관 과와 도구의 1순위 추천을 문항별로 대조해 **30건 이상** 일치하면 정확도 기준을 통과한다. 동률·무일치·공통 문항은 임의 확정하지 않고 확인필요 또는 후보로 표시되는지 확인한다. 대장 520행을 불러왔을 때 행·접수번호가 누락되지 않는지, 원본의 배분구분(소관 450건·공통 70건)과 처리상태(제출완료 412건·기한연장 55건·보완요청 53건)가 유지되는지 대조한다. 문항 분해·중복·기간·기한·부서명 점검의 실제 검출 성능은 원본 요구서 또는 오류 정답표가 있어야 별도로 검증할 수 있으며, 대장만으로 통과를 주장하지 않는다. 사람이 확정·수정한 배분을 다시 조회해 담당자·시각·사유와 이전 값이 남는지 확인한다. |
