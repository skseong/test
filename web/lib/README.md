# 브라우저 라이브러리

이 폴더의 스크립트는 버전을 고정해 웹앱에 포함합니다. 업무 문항 데이터는 포함하지 않습니다.

| 파일 | 버전 | 출처 | 용도 |
|---|---|---|---|
| `papaparse.min.js` | 5.5.3 | https://www.papaparse.com/ | CSV 파싱 |
| `xlsx.full.min.js` | 0.20.3 | https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js | 엑셀 읽기·쓰기 |
| `chart.umd.min.js` | 4.5.0 | https://www.chartjs.org/ | 과별 배분 현황 |
| `pdf.min.js`, `pdf.worker.min.js` | 3.11.174 | https://mozilla.github.io/pdf.js/ | 브라우저 PDF 읽기 |

Fuse.js와 Tabulator는 화면 설계에서 선택 사항이며, 현재 배분 규칙은 CSV 기준표와 기본 표를 사용합니다.
